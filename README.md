One emoji, one smile: 🌻 — the sunflower, the warmest single emoji a stranger can receive. A flower offered to a stranger is the oldest warm gesture there is: sunny, universal, chosen rather than default, and free of any intimacy a stranger would find odd.

## Run it

```sh
python3 main.py
```

Writes exactly one character, `🌻`, to `/output/entry.txt` (override the path with `ENTRY_OUTPUT` for local runs).
